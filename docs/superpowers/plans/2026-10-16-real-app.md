# TubeScope Implementation Plan

> **For agentic workers:** Implement the following scoped tasks using the shared API contract; use superpowers:dispatching-parallel-agents for independent backend/frontend file ownership and a fresh reviewer at integration.

**Goal:** Deliver a real local YouTube metadata research application with a persistent warehouse.
**Architecture:** Next.js proxies a Python API; a bounded durable SQLite job queue runs yt-dlp subprocesses. SQLite stores only approved metadata and separately preserves review data.
**Tech Stack:** Next.js/React/TypeScript, Tailwind/shadcn, FastAPI, SQLite/FTS5, yt-dlp, pytest.
**Spec:** `docs/spec.md`; exact interfaces `docs/api-contract.md`.

## Global Constraints
- 17 metadata groups, exclude comments/counts, subtitle text, heatmap, formats and media files.
- Vietnamese UI. Sources required *, optional defaults. Full mode and100/source defaults.
- Local binding, no seeded fake data, no authentication integration.
- Paginated SQLite queries, unique video IDs, durable jobs, preserve review on refresh.

## Review Focus
- Partial extraction fields and null versus zero.
- Repeated crawl/upsert versus review data loss.
- Malformed source URLs and arbitrary flags.
- Cancellation/restart while a subprocess runs.
- Pagination/filter/export consistency and many-to-many playlist membership.
